# Hugging Face cell: technology registry

Format: `research/technology-registry/FORMAT.md`. One row per technology. Read with `REPORT.md`
(evidence, sizes, VRAM, browser status and the per-need matrix).

How "Verified on" was filled:
- **2026-11-09** = on that date I read the model card's `license` field myself through the Hugging Face
  MCP (`hub_repo_details`, and `hf_fs cat README.md / LICENSE` for every `license: other`). Code licences
  come from the repo's own `LICENSE` file on raw.githubusercontent.com, read the same day.
- "(code not re-read)" = the weights licence was verified, but I could not open the code repo's LICENSE
  file today.
- **unverified** = gated card I could not open. The licence shown comes from a secondary source.

Scoring: Quality /20, Ziggy fit /20, Perf /15, Maturity /10, Docs /10, Licence & commercial /15,
Running cost /10. Non-commercial, research-only, EU-excluded or undeclared weights score 0 on licence
and are never "adopt". Running cost: 10 = runs offline on a CPU or in the browser for free. 9 = an
offline bake that needs a one-off GPU (rented, or the owner's own machine), with zero runtime cost.
